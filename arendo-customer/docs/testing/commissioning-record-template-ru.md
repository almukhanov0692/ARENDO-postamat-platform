# Протокол выездной проверки Modbus, реле и обратных сигналов

Заполнять при наладке на объекте. Один протокол фиксирует одну конфигурацию оборудования и ПО; при изменении проводки, Modbus-параметров или сборки создать новую редакцию. Пустые строки означают «не проверено», а не «исправно».

## 5. Проверка релейных выходов и замков

На каждой задействованной двери проверить полный путь: команда приложения/сервера → Modbus-запись → переключение реле → питание замка → фактическое открытие → обратный сигнал → отображение результата.
