# Modbus Poll — снимки настроек пользователя

Эти изображения из прежнего разговора сохранены для справки. Они не являются протоколом успешного подключения или испытания реле.

- 01: COM11, 9600 baud, 8 data bits, Even Parity, 1 Stop Bit (8E1).
- 02: список доступных типов соединения в Modbus Poll.
- 03: окно Write Multiple Registers, функция 16, Slave ID 1, Address 0, Quantity 10.

В руководстве BSM указаны заводские 9600 8N1, поэтому чётность на первом снимке отличается. Руководство описывает функции 05 и 0F для управления выходами; функция 16 из третьего скриншота не подтверждена как команда управления реле.

Адрес модуля меняется через фирменную Modbus_BSI, в меню «Инструменты» → «Параметры связи модуля». Поле Slave ID в Modbus Poll только выбирает адрес, к которому мастер обращается. Порядок и режим DIP-переключателей сверяйте со страницей 5 руководства и только после проверки точной модели платы.
