# BSM series manual — страницы из исходного экспорта

Сохранены 9 страниц PNG руководства BSM из пользовательского экспорта Baidu, датированного 25 сентября 2026 года. Исходный PDF в доступных папках не найден.

- Страница 5: связь с модулем и настройка номера станции через Modbus_BSI, меню «Инструменты» → «Параметры связи модуля».
- Страницы 6–7: функции Modbus для входов и выходов; одиночный выход — функция 05, несколько выходов — функция 0F.
- Заводские параметры в руководстве: 9600 8N1, адрес станции 1.
- Руководство описывает DIP-переключатели для режима настройки и обычного режима. Перед настройкой нужно проверить модель, ревизию и маркировку именно этой платы.

В профилях проекта отдельно описаны [демонстрационная BSM-0410RB](../bsm-0410rb-demo.md) и [кандидат BSM-1616RB](../bsm-1616rb.md). Их фактическую модель и тип выходов требуется подтвердить на оборудовании.
