# E-003 — предлагаемая карта Modbus-каналов D01–D32 (R0)

Дата: 30.09.2026. Статус: **программная/проектная карта для согласования; НЕ монтажная ведомость**.

Цель — показать, как однозначно маршрутизировать логическую ячейку по одной общей шине RS-485,
если в постамате используются две платы BSM-1616RB. Модульный адрес выбирает плату, локальный
адрес входа/выхода — канал на этой плате. Повторяющиеся подписи X1/Y1 на разных платах не
конфликтуют, если slave ID разные.

## Предлагаемое распределение

- M1: BSM-1616RB, предлагаемое Modbus ID `1`, D01–D16.
- M2: BSM-1616RB, предлагаемое Modbus ID `2`, D17–D28; каналы 13–16 остаются резервом.
- Общая линия: один Modbus RTU master и один RS-485 сегмент; A соединяется с A, B с B. Адреса
  `1` и `2` требуется записать/проверить на физических платах и после перезапуска питания.
- Целевой постамат имеет 28 установленных ячеек. D29–D32 в таблице — только резервные I/O каналы,
  не двери и не `cellCode`, которые нужно создавать на сервере.
- Адреса Modbus в таблице нулевые: X1/Y1 = адрес 0, X16/Y16 = адрес 15. Физическую маркировку,
  ревизию платы, схему клемм и назначение кабелей подтвердить на полученном оборудовании.

## Пример маршрутизации

Команда для `cellCode="18"` направляется на модуль M2 (`slave ID 2`) и локальный канал 2:
вход X2 и выход Y2, Modbus point address 1. Она **не** означает Y18 на первой плате.

Backend видит только `postamatId`, `cellCode` и идентификаторы операции. Slave ID, X/Y, Modbus
адреса и USB/RS-485 остаются внутренней конфигурацией устройства.

## Ограничения и подтверждение

Это предлагаемая software fixture, совместимая с имеющимся `proposedSequential28(1, 2)` и его
unit-тестами. Она не доказывает, что физические платы уже настроены на адреса 1 и 2, что кабели
проложены именно так, или что сигнал X определяет физическое положение двери. Перед вводом нужны:

1. Настроить уникальные slave ID и подтвердить обнаружение обеих плат на общей шине.
2. Проверить адресацию каждой платы, чтение входов и импульс ровно одного выхода за тест.
3. Установить соответствие между физическим шкафом/ячейкой, `cellCode`, X и Y.
4. Проверить на выбранном замке, сообщает ли его сигнальная пара положение двери, состояние
   механизма либо иной факт; зафиксировать обрыв/неизвестное состояние.
5. Выпустить монтажную ревизию R1 с клеммами, защитой, кабелями, источником и проверенными
   номиналами после получения оборудования.
